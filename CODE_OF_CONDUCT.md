# Code of Conduct

We want JevShield to be a constructive security research community.

Expected behavior:

- Be respectful and technically rigorous.
- Assume good intent while challenging technical claims.
- Do not publish private information.
- Do not use project discussions to facilitate harm against third parties.
- Give attribution for research, datasets and prior work.

Unacceptable behavior includes harassment, discrimination, doxxing, credential disclosure and deliberate abuse of project infrastructure.
