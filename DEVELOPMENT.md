# Development Guide

## Prerequisites

- Node.js 20+
- npm

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

## Test

```bash
npm test
```

## Lint

```bash
npm run lint
```

## Security test corpus

Fixtures live under `tests/fixtures`. Every detector should have both positive and negative examples.

## Commit style

Prefer:

- `feat:`
- `fix:`
- `security:`
- `test:`
- `docs:`
- `refactor:`
