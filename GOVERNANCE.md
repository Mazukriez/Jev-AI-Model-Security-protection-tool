# Governance

JevShield is maintained as an open-source project under the repository owner and community contributors.

## Maintainers

Maintainers review security-sensitive changes, approve releases and protect the project's security baseline.

## Decision process

Technical proposals should be discussed through GitHub issues or pull requests. Security-impacting changes require tests and an explicit threat-model discussion.

## Becoming a maintainer

Consistent contributors may be invited to maintainer roles based on sustained quality, security judgment, review participation and community conduct.

## Compatibility

Changes should preserve the public scanner contracts unless a breaking change is explicitly documented.
