# Security Policy

## Scope

JevShield is security tooling. Vulnerabilities in this repository may affect users who deploy it as an application security control.

## Reporting

Do not publish an exploitable vulnerability in a public issue. Use GitHub's private security reporting mechanism when enabled for this repository, or contact the project maintainers privately through the repository owner.

## Report contents

Please include:

- Affected version/commit
- Component
- Reproduction steps
- Security impact
- Suggested mitigation, if known

Do not include real secrets or personal/customer data.

## Design principle

JevShield findings are security signals, not proof of malicious intent. Detection and policy enforcement must remain separately testable.
